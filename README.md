# Fault-Tolerant Distributed Task Queue & Data Pipeline Engine

## Project Overview
A Python-based task queue system designed to manage, execute, track, and retry tasks using SQLite database persistence.

## Features
- Add and delete tasks
- Execute individual tasks
- Execute all pending tasks
- Automatic retry mechanism
- Manual retry mechanism
- Task failure handling
- Search tasks by ID
- Filter tasks by status
- Task statistics
- SQLite database persistence
- Input validation

## Technologies Used
- Python
- SQLite
- VS Code

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python task_queue.py
```
